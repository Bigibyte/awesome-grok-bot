# Who is it for

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.

Quick cards. If none fit, you can still use Grok Bot as a single research teammate.

| Who | Why it fits | Start here |
|-----|-------------|------------|
| **Founders / chiefs of staff** | Digests, prioritization, multi-bot hub | [Starter: Bot Boss style](starter-bots.md) · [Grok Bot for Work](https://x.ai/bot/guides/grok-bot-for-work) |
| **Sales** | Account research + draft outreach, approve before send | [Use cases](use-case-recipes.md#sales) · [official use cases](https://docs.x.ai/grok-bot/use-cases) |
| **Recruiters** | Shortlists and outreach drafts | [Use cases](use-case-recipes.md#recruiting) |
| **Marketers** | Spend reviews and Slack drafts without changing budgets | [Use cases](use-case-recipes.md#marketing--paid-media) |
| **Ops / finance** | Expense digests, follow-ups | [Use cases](use-case-recipes.md#ops--finance) |
| **Engineers / PMs** | Bug repro packs, trackers, Cloud Agent handoffs | [Feature examples: Cloud Agents](feature-examples.md#cursor-cloud-agents) |
| **Students / solo makers** | Research Pages, reminders, inbox triage | [Learning path: Beginner](learning-path.md#beginner) |
| **Teams / Enterprise** | Shared Bots, admin controls, network policy | [Teams docs](https://docs.x.ai/grok-bot/teams-and-enterprises) |

> [!NOTE]
> Grok Bot is **not** the same as Grok chat on grok.com. Source: [FAQ](https://docs.x.ai/grok-bot/faq).

# Keyboard shortcuts (desktop)

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.

> [!NOTE]
> Verified from [Message and collaborate](https://docs.x.ai/grok-bot/chat-and-collaboration) (Oct 28, 2026) and [Settings and notifications](https://docs.x.ai/grok-bot/settings-and-notifications). Use **Cmd** on macOS and **Ctrl** on Windows/Linux unless a row says otherwise. Unverified blog chords are omitted.

In-app sheet: account menu → Support → Keyboard shortcuts, or `Cmd/Ctrl+/`.

## Navigation and search

| Action | Shortcut |
|--------|----------|
| Jump to / search palette | `Cmd/Ctrl+K` |
| Search Bots | `Cmd/Ctrl+Shift+F` |
| New Bot | `Cmd/Ctrl+N` |
| New group chat | `Cmd/Ctrl+Shift+N` |
| Show all keyboard shortcuts | `Cmd/Ctrl+/` |
| Find in this chat | `Cmd/Ctrl+F` |
| Compact sidebar | `Cmd/Ctrl+B` |
| Sidebar Bot 1 to 9 | `Cmd/Ctrl+1` ... `Cmd/Ctrl+9` |
| Previous / next Bot | `Alt+↑` / `Alt+↓` |
| Back / forward in visit history | `Cmd/Ctrl+[` / `Cmd/Ctrl+]` |
| Cycle Bots | `Control+Tab` / `Control+Shift+Tab` (always Control, including on macOS) |

## Composer and voice

| Action | Shortcut |
|--------|----------|
| Focus prompt | `Cmd/Ctrl+I` |
| Add selected text to chat | `Cmd/Ctrl+L` |
| Send | `Enter` in composer, or `Cmd/Ctrl+Enter` from anywhere |
| New line | `Shift+Enter` |
| Dictate | `Cmd/Ctrl+D` while prompt focused |
| Start voice chat | Composer button only (no keybinding) |

## Apps, Bot pane, settings

| Action | Shortcut |
|--------|----------|
| Connect apps | `Cmd/Ctrl+Shift+M` or `Cmd/Ctrl+Shift+W` |
| Toggle Bot settings | `Cmd/Ctrl+Shift+,` |
| Conversation details | `Cmd+Shift+I` or `Cmd+Alt+B` (macOS); `Ctrl+Alt+B` (Windows/Linux) |
| Open Settings | `Cmd/Ctrl+,` |

## Zoom and window

| Action | Shortcut |
|--------|----------|
| Zoom in / out / reset | `Cmd/Ctrl+=` / `Cmd/Ctrl+-` / `Cmd/Ctrl+0` |
| Fullscreen | `F11`; on macOS also `Control+Cmd+F` |

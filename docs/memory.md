# Memory

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.

Bots can remember job rules, preferences, and facts you ask them to keep. Memory is powerful and easy to mess up. Keep it intentional.

## What to store

- Job description and never-do rules
- Preferred output formats
- Names of skills and routines that belong to that Bot
- Stable facts about your projects (not one-off secrets)

## What not to store casually

- Passwords, API keys, card numbers (use Vault / Secure Form instead)
- Temporary gossip or one-time codes
- Anything you would not want another Bot on the same computer to reach indirectly

<details>
<summary><strong>Click: how to update memory</strong></summary>

<br>

1. Correct the Bot in chat: "Remember: always include sources."
2. Ask it to forget something outdated.
3. Re-state the job when you change roles.

</details>

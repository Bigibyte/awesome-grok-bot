Check boxes as you go. Jump links open the matching guide.

## Beginner

- [ ] Read the [TL;DR on the README](../README.md#tldr-30-seconds)
- [ ] Install and finish [Getting started](getting-started.md)
- [ ] Send one safe draft-only task ([step by step Day 1](step-by-step.md))
- [ ] Skim [Who is it for](who-is-it-for.md) and [Limits](limits.md)
- [ ] Learn [Keyboard shortcuts](keyboard-shortcuts.md) you will use daily (`Cmd/Ctrl+K`, `Cmd/Ctrl+,`, `Cmd/Ctrl+D`)
- [ ] Copy one prompt from [Prompt library](prompt-library.md)

## Intermediate

- [ ] Create a second Bot from [Starter bots](starter-bots.md)
- [ ] Save a [skill](skills.md) and run it twice
- [ ] Connect one app ([connectors](connectors.md))
- [ ] Build one [Page](pages.md) into Library
- [ ] Turn a skill into a Disabled [routine](routines.md), test, then Enable
- [ ] Read [Safety and privacy](safety-privacy.md)

## Power user

- [ ] Run a [multi-bot workflow](workflows.md#example-2-social-post-pipeline-multi-bot)
- [ ] Study [Feature examples](feature-examples.md) end to end
- [ ] Compare tools in [Comparisons](comparisons.md) with sources open
- [ ] Add an email or Slack draft routine with approvals on
- [ ] Practice Vault / Secure Form habits before any purchase path
- [ ] Skim [Recent updates](recent-updates.md) monthly

> [!TIP]
> Stuck? Open [Troubleshooting](troubleshooting.md).

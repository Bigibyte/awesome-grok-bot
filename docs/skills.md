# Skills

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.

Skills are reusable how-to instructions. Teach once, call often. Source: [skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations).

## Ways to create a skill

<details open>
<summary><strong>Three paths</strong></summary>

<br>

1. **After a good run:** "Save this process as a skill named Weekly competitor brief."
2. **Teach a task:** record a browser workflow (up to 10 minutes).
3. **Write it yourself:** paste clear steps, constraints, and the output format.

</details>

## Good skill shape

```
Name: clear and short
When to use: one sentence
Steps: numbered
Inputs needed: list
Output: file / Page / draft text
Never: send, post, buy, delete without approval
```

## Skill vs routine

| | Skill | Routine |
|-|-------|---------|
| Meaning | How to do the work | When to run |
| Trigger | You ask for it | Schedule or event |
| Example | "Competitor brief method" | "Every Monday 9:00" |

> [!TIP]
> Call skills by name: "Run skill Weekly competitor brief for Acme."

# Connectors, apps, and agent email

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.

Connect apps give Bots structured access to tools like Gmail, Slack, Notion, and GitHub. Prefer a connector over logging in through the browser when both options exist. Source: [computer and apps](https://docs.x.ai/grok-bot/computer-and-apps).

## Checklist: connect an app

- [ ] Open **Connect apps** in Grok Bot
- [ ] Pick the app and finish OAuth or the setup flow
- [ ] Tell the Bot which connected app to use
- [ ] Keep "draft only" rules until you trust the flow

## Agent email

Grok Bot can use an agent email address on `mail.grokbot.com`. Useful for Bots that need to receive or send mail as part of a workflow. Confirm current limits in the [FAQ](https://docs.x.ai/grok-bot/faq).

# Cheat sheet

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.

<p align="center">
  <img src="https://images.bigibyte.com/projects/bigibyte-github-awesome-grok-bot-v2-sec-getting-started.png" alt="Cheat sheet" width="100%">

- Install: [x.ai/bot](https://x.ai/bot) · Cursor sign-in · name Bot after a job
- Five-part task: Outcome · Sources · Constraints · Deliverable · Stop
- Skill = how · Routine = when
- Shared cloud PC for all Bots
- Prefer Connect apps · draft before send · Pages for lasting reports · Vault for secrets
- Daily shortcuts: `Cmd/Ctrl+K` · `Cmd/Ctrl+,` · `Cmd/Ctrl+D` · `Cmd/Ctrl+/`

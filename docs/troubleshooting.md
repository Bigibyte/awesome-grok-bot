# Common mistakes and fixes

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.

<p align="center">
  <img src="https://images.bigibyte.com/projects/bigibyte-github-awesome-grok-bot-v2-sec-safety.png" alt="Troubleshooting" width="100%">
</p>

<details>
<summary><strong>Treating Grok Bot like Grok chat</strong></summary>

<br>

Install the Bot app and create named Bots. Source: [FAQ](https://docs.x.ai/grok-bot/faq).

</details>

<details>
<summary><strong>One Bot that does every job</strong></summary>

<br>

Split roles. Use group chat or Bot Boss. Sources: [overview](https://docs.x.ai/grok-bot/overview), [Grok Bot for Work](https://x.ai/bot/guides/grok-bot-for-work).

</details>

<details>
<summary><strong>Assuming Bots isolate logins</strong></summary>

<br>

One shared computer. Source: [computer and apps](https://docs.x.ai/grok-bot/computer-and-apps).

</details>

<details>
<summary><strong>Enabling a routine before a manual test</strong></summary>

<br>

Create Disabled, run once, then Enable.

</details>

<details>
<summary><strong>Looking for a gear icon for Settings</strong></summary>

<br>

Account menu, `Cmd/Ctrl+,`, or palette. Source: [settings](https://docs.x.ai/grok-bot/settings-and-notifications).

</details>

<details>
<summary><strong>Expecting a voice-chat shortcut</strong></summary>

<br>

Use the composer button. Dictate is `Cmd/Ctrl+D`. Source: [chat and collaboration](https://docs.x.ai/grok-bot/chat-and-collaboration).

</details>

<details>
<summary><strong>Pages missing</strong></summary>

<br>

Update app; check Enterprise limits. Source: [files and results](https://docs.x.ai/grok-bot/files-and-results).

</details>

<details>
<summary><strong>Pasting passwords in chat</strong></summary>

<br>

Use Vault / Secure Form. Source: [approvals](https://docs.x.ai/grok-bot/approvals-security-and-privacy).

</details>

## Computer recovery

Prefer **Update Bot's Computer** over **Reset**. See [settings](https://docs.x.ai/grok-bot/settings-and-notifications).

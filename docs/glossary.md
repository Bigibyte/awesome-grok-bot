# Glossary

> [!TIP]
> If this guide helps you, please give it a [star](https://github.com/bigibyte/awesome-grok-bot) so more people can find it.


| Term | Meaning |
|------|---------|
| **Bot** | Named AI teammate with a job and memory |
| **Cloud computer** | Persistent browser + files + terminal for your account |
| **Connect apps** | Structured plugins (Gmail, Slack, GitHub, ...) |
| **Skill** | Reusable how-to |
| **Teach a task** | Record a browser workflow into a skill |
| **Routine** | Skill/instructions on a schedule or event |
| **Page** | Lasting report/dashboard in Library |
| **Library** | Per-Bot list of Pages, files, media, links |
| **Approval** | Pause for your OK |
| **Auto Review** | Extra review on risky actions |
| **Vault** | Saved credentials filled by reference |
| **Secure Form** | Type secrets without normal chat exposure |
| **Agent email** | `mail.grokbot.com` address |
| **Group chat** | Thread with several Bots |
| **Cloud Agent** | Separate Cursor coding computer a Bot can delegate to |
| **Voice chat** | Live spoken call with one Bot |
| **Grok chat** | Separate product on grok.com |

Sources: [overview](https://docs.x.ai/grok-bot/overview), [FAQ](https://docs.x.ai/grok-bot/faq), [files and results](https://docs.x.ai/grok-bot/files-and-results), [chat and collaboration](https://docs.x.ai/grok-bot/chat-and-collaboration).

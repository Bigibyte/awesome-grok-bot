# Brand palette (community interpretation)

Based on public Grok / x.ai / Grok Bot surfaces (near-black UI, white type, high-contrast accents). Not an official brand kit dump.

| Token | Hex | Use |
|-------|-----|-----|
| Void black | `#0A0A0A` | Cover / section backgrounds |
| Soft black | `#111111` | Card backgrounds |
| Ink | `#171717` | Secondary panels |
| Pure white | `#FFFFFF` | Primary headlines |
| Soft white | `#E5E5E5` | Body text on dark |
| Muted | `#A3A3A3` | Captions |
| Grok accent | `#FFFFFF` hairline + subtle cool gray `#D4D4D4` | Borders |
| Signal | `#F5F5F5` on black | Badge fills for dark shields |

Shields in README use near-black (`0A0A0A`) with white/light labels to match.
